### 2. Proxy Rotation for DNS/Network Errors 🔄

**File**: [src/crawler/__init__.py](src/crawler/__init__.py)
- New method: lines ~1137-1180 (`_handle_connection_error_with_proxy_escalation()`)
- Integrated in newspaper handler: line ~3495
- Integrated in beautifulsoup handler: line ~3726

**What**: When connection errors occur (DNS failures, timeouts, network resets), automatically rotate to different proxy and retry

**Why**: Some sites are network-blocked or have DNS issues that vary by proxy provider. Rotating proxies can bypass these blocks.

**Code**:
```python
def _handle_connection_error_with_proxy_escalation(self, domain: str, error: Exception):
    """Detect connection errors and rotate proxy for retry"""
    error_str = str(error).lower()
    is_connection_error = any(
        indicator in error_str
        for indicator in ["connection", "timeout", "dns", "namenotfound", 
                         "gaierror", "refused", "reset by peer"]
    )
    if not is_connection_error:
        return
    
    # Rotate to different proxy
    if domain in self.domain_proxies:
        new_proxy = random.choice([p for p in self.proxy_pool if p != current])
        self.domain_proxies[domain] = new_proxy
```

### 3. CAPTCHA Backoff (Already Implemented) ✅

**File**: [src/crawler/__init__.py](src/crawler/__init__.py) (line ~1808)

**What**: When CAPTCHA detected and all extraction methods fail, apply exponential backoff (10 min → 20 min → 40 min → 90 min)

**Why**: CAPTCHA means bot, so aggressive backoff prevents wasting resources. Auto-retry after cooldown period.

**Code** (already present):
```python
def _handle_captcha_backoff(self, domain: str) -> None:
    """Apply extended backoff for CAPTCHA/challenge detections"""
    count = self.domain_error_counts.get(domain, 0) + 1
    delay = min(base * (2 ** (count - 1)), cap)  # Exponential backoff
    self.domain_backoff_until[domain] = now + delay
    logger.warning(f"CAPTCHA backoff for {domain}: {int(delay)}s (attempt {count})")
```

## Extraction Flow After Changes

```
Article Extraction
    ↓
[Check Domain Protection Type]
    ├─→ Cloudflare + CloudScraper? 
    │   YES → Try CloudScraper FIRST (skip Selenium jump) ⚡ 
    │   Fail → BeautifulSoup → Selenium fallback
    │
    ├─→ DNS/Network Error during Request?
    │   YES → Rotate proxy → Retry with different proxy 🔄
    │   Fail → Try fallback methods
    │
    └─→ All Methods Fail + CAPTCHA Detected?
        YES → Apply exponential backoff (10-90 min) then retry 🛑
        NO → Standard rate-limit backoff
```
