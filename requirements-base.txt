# The shapes one service in the suite writes and another reads. The review
# hold note is written here and read by the datadesk console; each
# repository having its own copy of the key names is what let a rename
# strand every held article.
#
# Pinned to a tag, never a branch: a shape must not change under a test
# run, and a release happens because somebody bumped a version in a
# reviewed pull request.
# From the release tarball, not git+https. This image is a SINGLE stage,
# and it installs no git -- its apt line is gcc, g++, libpq-dev, wget,
# ca-certificates and procps. A git dependency cannot be fetched without
# git, so the build failed at pip install.
#
# Adding git would have shipped it to the runtime image for the sake of one
# build-time fetch. datadesk installs the same tag over git+https because
# its build is multi-stage and git never leaves the builder.
